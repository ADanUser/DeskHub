# DeskHub

Платформа для поиска и бронирования мест в коворкингах.

## Описание
DeskHub позволяет пользователям находить коворкинги в разных городах, фильтровать доступные слоты по дате и типу (рабочее место, переговорная), добавлять их в корзину и оформлять бронирование.

## Стек технологий
- **Python 3.12+**
- **Django 6.0**
- **PostgreSQL**
- **HTML/CSS (Bootstrap)**
- **JavaScript (AJAX)**

## Установка и запуск

### 1. Клонирование репозитория
```bash
git clone <repository_url>
cd deskhub
```

### 2. Настройка окружения
Создайте и активируйте виртуальное окружение:

**macOS/Linux:**
```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установка зависимостей
```bash
pip install django python-dotenv psycopg2-binary
```

### 4. Настройка переменных окружения
Создайте файл `.env` в корне проекта (рядом с `manage.py`) и добавьте следующие настройки:

```env
SECRET_KEY=your_secret_key_here
DEBUG=True
DB_NAME=deskhub_db
DB_USER=postgres
DB_PASSWORD=root
DB_HOST=localhost
DB_PORT=5432
```
> **Важно:** Убедитесь, что PostgreSQL запущен и база данных `deskhub_db` создана.

### 5. Применение миграций
```bash
python manage.py migrate
```

### 6. Заполнение базы данных тестовыми данными
Чтобы быстро наполнить проект коворкингами, слотами и городами для тестирования, выполните команду:
```bash
python manage.py populate_db
```
> **Внимание:** Эта команда очистит текущие данные (города, коворкинги, слоты) и создаст новые.

### 7. Создание суперпользователя (Администратора)
```bash
python manage.py createsuperuser
```

### 8. Запуск сервера
```bash
python manage.py runserver
```
Проект будет доступен по адресу: [http://127.0.0.1:8000/](http://127.0.0.1:8000/)

## Функционал
- **Поиск**: Фильтрация по городу, дате, типу ресурса.
- **Корзина**: Добавление слотов в корзину (сессии).
- **Бронирование**: Оформление заказа с проверкой доступности и блокировкой слотов.
- **Личный кабинет**: Просмотр статуса броней и история.
- **API**: JSON endpoints для получения списка коворкингов и броней.

## Структура проекта
- `venues/`: Управление коворкингами и слотами.
- `users/`: Регистрация и авторизация.
- `bookings/`: Корзина и оформление бронирований.
- `templates/`: HTML-шаблоны.
