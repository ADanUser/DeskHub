## Короткое описание проекта

DeskHub — веб-приложение на Django для поиска и бронирования рабочих мест и переговорных комнат в коворкингах. Пользователь выбирает город, дату и тип ресурса, добавляет слот в корзину, оформляет бронирование и видит свои брони в личном кабинете. Администратор управляет городами, коворкингами, слотами и статусами бронирований через Django Admin.

## Главные темы для собеседования

1. Django MVT: `models`, `views`, `templates`, `urls`.
2. ORM и связи моделей: `ForeignKey`, `OneToOneField`, `AbstractUser`.
3. Сессии: корзина хранится в `request.session['cart']`.
4. Авторизация: регистрация, вход, выход, `@login_required`.
5. Транзакции: `transaction.atomic()` и `select_for_update()` при checkout.
6. API без DRF: `JsonResponse`.
7. PostgreSQL и переменные окружения через `.env`.
8. Оптимизация запросов: `select_related()`, пагинация.
9. Безопасность: CSRF, SECRET_KEY в `.env`, не хранить секреты в коде.
