# DeskHub — обзор проекта

## Что это за проект

DeskHub — платформа для поиска и бронирования мест в коворкингах. Проект реализован как классическое Django-приложение с серверным рендерингом HTML-шаблонов и небольшими JSON API.

## Какую задачу решает

Пользователю нужно быстро найти свободное рабочее место или переговорную комнату в нужном городе и забронировать подходящий временной слот. Без такой системы пользователь должен вручную искать коворкинги, уточнять наличие мест и договариваться о бронировании.

## Основной функционал

- регистрация, вход и выход пользователя;
- поиск коворкингов по городу;
- фильтрация доступных слотов по дате и типу ресурса;
- просмотр карточки коворкинга;
- добавление слотов в корзину;
- хранение корзины в сессии;
- оформление бронирования;
- проверка доступности слотов при оформлении;
- личный кабинет с историей бронирований;
- отмена бронирования пользователем;
- управление данными через Django Admin;
- JSON API для коворкингов и бронирований.

## Стек

- Python 3.12+
- Django 6.0.1
- PostgreSQL
- Django Templates
- Bootstrap 5
- JavaScript `fetch` для AJAX-добавления в корзину
- `python-dotenv` для переменных окружения
- `psycopg2-binary` для подключения к PostgreSQL
- Pillow для работы с изображениями коворкингов

## Почему выбран Django

Django хорошо подходит для такого проекта, потому что «из коробки» даёт:

- ORM для работы с БД;
- систему маршрутизации;
- шаблоны;
- миграции;
- авторизацию и сессии;
- админ-панель;
- защиту от типовых web-уязвимостей.

Для junior-проекта это сильный выбор: можно показать понимание backend, базы данных, шаблонов, авторизации и базовой архитектуры.

## Основные Django-приложения

- `deskhub` — настройки проекта, корневые URL, middleware.
- `users` — кастомная модель пользователя, регистрация, вход, выход.
- `venues` — города, коворкинги, слоты, поиск, страницы каталога, API коворкингов.
- `bookings` — корзина, оформление бронирований, отмена, API бронирований.

## Что можно сказать на собеседовании

«Я сделал Django-приложение для бронирования коворкингов. Разделил проект на несколько приложений по доменным зонам: пользователи, площадки и бронирования. Использовал PostgreSQL, Django ORM, шаблоны, сессии для корзины и транзакции при оформлении бронирования, чтобы избежать ситуации, когда два пользователя одновременно бронируют один слот.»
