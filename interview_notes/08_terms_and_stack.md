# Термины и стек

## Python

Python — основной язык проекта. На нём написаны модели, views, формы, middleware и management command.

## Django

Django — backend web framework. В проекте отвечает за:

- маршрутизацию;
- ORM;
- шаблоны;
- авторизацию;
- сессии;
- миграции;
- админку;
- middleware.

## PostgreSQL

PostgreSQL — реляционная база данных. В ней хранятся пользователи, города, коворкинги, слоты и бронирования.

## ORM

ORM позволяет работать с таблицами БД через Python-классы.

Пример:

```python
Venue.objects.filter(city_id=city_id)
```

## Migration

Миграция — файл изменения структуры базы данных. Создаётся командой:

```bash
python manage.py makemigrations
```

Применяется командой:

```bash
python manage.py migrate
```

## Model

Model — Python-класс, который описывает таблицу БД.

## View

View — обработчик HTTP-запроса.

## Template

Template — HTML-шаблон с Django Template Language.

## URLconf

URLconf — файл маршрутов, который связывает URL с view.

## Session

Session — механизм хранения данных между запросами пользователя. В DeskHub сессия используется для корзины.

## Middleware

Middleware — промежуточный слой обработки запроса и ответа. В проекте middleware логирует запросы и добавляет данные корзины в `request`.

## `ForeignKey`

Связь многие-к-одному. Например, много коворкингов относятся к одному городу.

## `OneToOneField`

Связь один-к-одному. В проекте один слот может иметь только одно бронирование.

## `transaction.atomic()`

Блок, внутри которого операции с БД выполняются как единая транзакция.

## `select_for_update()`

Метод ORM, который блокирует выбранные строки БД до конца транзакции.

## `select_related()`

Оптимизация ORM-запросов для связей `ForeignKey` и `OneToOneField`. Загружает связанные объекты через JOIN.

## `JsonResponse`

Django-класс для возврата JSON-ответа.

## CSRF

CSRF — атака, при которой злоумышленник пытается выполнить действие от имени пользователя. Django защищает формы через CSRF token и middleware.

## Bootstrap

CSS-фреймворк для быстрой стилизации интерфейса.

## AJAX

AJAX позволяет отправлять запросы на сервер без полной перезагрузки страницы. В проекте используется `fetch()` для добавления слота в корзину.

## `.env`

Файл с переменными окружения: `SECRET_KEY`, настройки БД, `DEBUG`. Секреты не должны храниться прямо в коде.
